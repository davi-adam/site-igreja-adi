# Site Institucional - ADI (Igreja Evangélica Assembléia de Deus Independente)

## Sobre o Projeto
Este repositório contém o desenvolvimento de um site institucional para uma igreja que atualmente não possui presença digital. O projeto é desenvolvido individualmente como parte do Projeto
Supervisionado de Extensão do curso de Análise e Desenvolvimento de Sistemas, com carga horária de 140h neste semestre.
